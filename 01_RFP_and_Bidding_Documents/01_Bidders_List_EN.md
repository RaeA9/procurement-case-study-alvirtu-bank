# Bidders List – AlVirtu Bank Core Banking System Project

**Date of Preparation:** July 10, 2026  
**Document Status:** Confidential (Internal Use Only)

---

## 1. Vendor (A) – Traditional Leader

| Attribute | Details |
| :--- | :--- |
| **Market Share** | Very high in major banks in the region. |
| **Estimated Cost** | $55M – $85M. |
| **Pricing Model** | Base license + additional modules (Islamic Banking, Wealth Management) sold separately. |
| **Hidden Fee Reputation** | High; notorious for charging extra for mandatory upgrades and customizations. |
| **Legal/Market Risks** | Has faced lawsuits for forcing hardware upgrades due to mandatory software updates, inflating costs by 30%. |
| **Typical SI Partner** | Tier-1 Global Consulting Firms. |
| **Preliminary Assessment** | Technically strong, but the most contractually complex. Requires strict governance to prevent (Unbundling Trap). |

---

## 2. Vendor (B) – Flexible Moderate

| Attribute | Details |
| :--- | :--- |
| **Market Share** | Very strong, especially in medium and large banks. |
| **Estimated Cost** | $50M – $95M. |
| **Pricing Model** | Reasonable base license; SI implementation costs are separated. |
| **Hidden Fee Reputation** | Moderate; the primary risk lies in the SI partner invoices (which can inflate). |
| **Legal/Market Risks** | Faced a class-action lawsuit in 2023 regarding the transparency of its maintenance revenue growth projections. |
| **Typical SI Partner** | Specialized Consulting Firms (e.g., Accenture, Deloitte). |
| **Preliminary Assessment** | Excellent flexibility, but requires strict governance over SI costs and (Joint & Several Liability) to prevent finger-pointing. |

---

## 3. Vendor (C) – Economical Aggressor

| Attribute | Details |
| :--- | :--- |
| **Market Share** | Strong competitor, but local presence is less dense. |
| **Estimated Cost** | $45M – $75M. |
| **Pricing Model** | Very attractive base license price. |
| **Hidden Fee Reputation** | Very High; known for exorbitant customization fees (Customization Ransom) that appear post-signing. |
| **Legal/Market Risks** | History of multiple acquisitions leading to instability in supporting older versions, pressuring clients to upgrade prematurely. |
| **Typical SI Partner** | Local or Regional Consulting Firms. |
| **Preliminary Assessment** | Tempting entry price, but it can turn into a financial trap during the customization phase. Requires (All-Inclusive Licensing) to prevent Unbundling. |

---

## 4. Vendor (D) – Cloud-Native Modern Option (Exploratory)

| Attribute | Details |
| :--- | :--- |
| **Market Share** | New player; built entirely on Microservices and cloud-native architecture. |
| **Estimated Cost** | $40M – $65M. |
| **Pricing Model** | Subscription-based (SaaS) or flexible licensing. |
| **Hidden Fee Reputation** | Relatively low; however, the cost of local experts is rare and very expensive. |
| **Legal/Market Risks** | Limited proven track record in large traditional banks in the region. |
| **Typical SI Partner** | Specialized Boutique Firms. |
| **Preliminary Assessment** | Recommended to be included as a Benchmark in the RFP to measure the pricing and technological gap, without commitment. |

## 5. Market Averages (Used as Baseline for Negotiations)

- **Total Project Estimate (License + Implementation + 5-year Maintenance):** $20M – $35M *(Note: This is an outdated baseline; actual Saudi market estimates are $50M – $120M)*.
- **Implementation Duration:** 18 to 24 months (depending on customization).
- **Typical Project Team Size:** 50 to 80 consultants at peak.

---

## 6. Lessons Learned from Previous Projects (Common Mistakes)

A. Underestimating integration costs with legacy systems: 40% of cost overruns occur here.
B. Vague scope definition for the SI partner: leads to unlimited Change Orders.
C. Overlooking training and knowledge transfer costs for local staff: can reach up to 20% of the contract value.
D. Ignoring the "Vendor Exit Cost" at the end of the contract.
