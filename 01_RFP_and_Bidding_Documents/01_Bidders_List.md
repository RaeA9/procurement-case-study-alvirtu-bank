# قائمة الموردين المحتملين – AlVirtu Bank Core Banking Project

**تاريخ الإعداد:** 10 يوليو 2026  
**حالة الوثيقة:** سرية (للاطلاع الداخلي)

---

## 1. المورد (أ) – الحل التقليدي الرائد

| الخاصية | التفاصيل |
| :--- | :--- |
| **السمعة** | رائد عالمي، حضور قوي في البنوك الكبرى بالمنطقة. |
| **التكلفة التقديرية** | 55 – 85 مليون دولار. |
| **نموذج التسعير** | ترخيص أساسي + وحدات إضافية (إسلامي، شركات، خزينة). |
| **الرسوم الخفية المتوقعة** | مرتفعة؛ يشتهر بفرض رسوم إضافية على الترقيات الإجبارية والتخصيصات. |
| **شريك التنفيذ النموذجي** | شركة استشارات كبرى (الفئة الأولى). |
| **التقييم المبدئي** | قوي تقنياً، لكنه الأكثر تعقيداً في عقوده. يحتاج حوكمة صارمة لمنع (Unbundling Trap). |

---

## 2. المورد (ب) – الحل المرن المعتدل

| الخاصية | التفاصيل |
| :--- | :--- |
| **السمعة** | قوي جداً في البنوك المتوسطة والكبيرة، مرونة عالية. |
| **التكلفة التقديرية** | 50 – 95 مليون دولار. |
| **نموذج التسعير** | ترخيص أساسي معقول، لكن تكلفة التنفيذ منفصلة (عبر شركاء). |
| **الرسوم الخفية المتوقعة** | متوسطة؛ الخطر الأكبر يكمن في فواتير شريك التنفيذ (System Integrator). |
| **شريك التنفيذ النموذجي** | شركات استشارات متخصصة (الفئة الثانية). |
| **التقييم المبدئي** | حل ممتاز من حيث المرونة، لكنه يتطلب إلزام المورد بـ (Joint & Several Liability) لضمان عدم تقاذف المسؤولية. |

---

## 3. المورد (ج) – الحل الاقتصادي المغري

| الخاصية | التفاصيل |
| :--- | :--- |
| **السمعة** | منافس قوي، لكن حضوره المحلي أقل كثافة. |
| **التكلفة التقديرية** | 45 – 75 مليون دولار. |
| **نموذج التسعير** | سعر ترخيص مغري جداً. |
| **الرسوم الخفية المتوقعة** | عالية جداً؛ يشتهر برسوم التخصيص (Customization) الباهظة التي تظهر بعد التوقيع. |
| **شريك التنفيذ النموذجي** | شركات محلية أو إقليمية. |
| **التقييم المبدئي** | سعر جذاب، لكنه قد يتحول إلى فخ مالي في مرحلة التخصيص والتكامل. يحتاج (All-Inclusive Licensing) لمنع تفكيك الوحدات. |

---

## 4. المورد (د) – الخيار الحديث (Cloud-Native) – للاستكشاف فقط

| الخاصية | التفاصيل |
| :--- | :--- |
| **السمعة** | لاعب جديد، مبني على الميكروخدمات (Microservices). |
| **التكلفة التقديرية** | 40 – 65 مليون دولار. |
| **نموذج التسعير** | قائم على الاشتراك (SaaS) أو ترخيص مرن. |
| **الرسوم الخفية المتوقعة** | منخفضة نسبياً، لكن تكلفة الخبراء المحليين نادرة ومكلفة. |
| **التقييم المبدئي** | يُنصح بإدراجه في الـ RFP كمرجع استكشافي (Benchmark) لقياس الفجوة السعرية والتقنية، دون الالتزام به. |
