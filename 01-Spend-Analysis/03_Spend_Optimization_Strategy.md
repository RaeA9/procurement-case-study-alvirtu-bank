# Spend Optimisation Strategy
## AlVirtu Bank — using the FY2023–FY2025 ledger to justify CBS replacement

**Prepared:** 1 February 2026  
**Owner:** Raed Al-Alanazi, Strategic Procurement  
**Inputs:** `01_Spend_Data_Model.xlsx`, `02_Spend_Analysis_Report.md`  
**Status:** Simulated educational case study

---

Spend analysis is not a chart pack. It is the brief that tells sourcing what to buy, what not to rebuy, and which clause must move money.

## 1. Consolidate the core book

The ledger shows nine suppliers and one category that already owns 63% of value.

- Place core licence, maintenance, Dev/Test, and the SI wrap in **one awarded instrument** (Vendor B in this case).
- Stop running a second consulting book (Vendor B historically) as a standing patch for an incumbent core (Vendor A). After award, consulting demand should fall to change-control, not life-support.
- Keep national rails (Vendor C) and local infrastructure as **named interfaces**, not competing cores.

Buying power comes from putting 81% of the book in front of two counterparties with a documented BATNA — not from splitting the same work across five software contracts.

## 2. Change the pricing model

| Current book | Target book |
| :--- | :--- |
| Perpetual core licence + **22.3%** FY2025 maintenance | Platform licence + **17.5%** maintenance frozen for seven years |
| Sandbox / Dev-Test as a separate opex line (USD 0.55m in FY2025) | Environments included — **USD 0** extra |
| Unbundled modules and after-hours as change orders | Islamic, treasury and 24/7 support inside the TCO |
| 15% advance with no bond | **10%** advance against a bank guarantee; **10%** performance bond |

Do not sell the programme as “30% cheaper IT.” Sell it as a rate reset plus the removal of hidden run-cost. The contracted seven-year value in the award file is **USD 51.65 million**.

## 3. Put the ledger under management

- Pay on milestones only. No large cash-out before a usable design and a passed UAT.
- Review Vendor A and Vendor B monthly; review the tail quarterly.
- Hold a quarterly category board: actual vs ledger, rate vs 17.5%, residency attestations, SLA credits.
- Any new auxiliary or cloud line that duplicates the awarded scope is a leakage event, not a new project.

## 4. What this file authorises next

1. Freeze Core Systems as the RFP category and write the knockout on data residency into the scorecard.
2. Carry the hidden-fee lines from this ledger into the five-year TCO before scoring.
3. Take only Vendor A (rewritten, on-kingdom, all-in licence) as BATNA. The historic A book is not an eligible award.
4. Move to folder `02-TPRM-Framework` for qualification and residual-risk treatment.

The number that matters for the board is not “we might save 30%.” It is: the incumbent rate is 22%, the sandbox is extra, two suppliers hold 81%, and replacement is the control that changes those three facts together.
