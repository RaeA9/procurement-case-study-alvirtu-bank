# Pre-Award Savings Levers

**Document ID:** COST-LEV-001  
**Institution:** AlVirtu Bank (simulated)  
**Date:** 1 February 2026  
**Inputs:** `01-Spend-Analysis`, TPRM-DDQ-001

---

A lower first-year licence is not a saving if maintenance, sandbox, and change-control reopen the same cash.

## 1. What the ledger already told us

| Fact from FY2023–FY2025 | Lever before RFP |
| :--- | :--- |
| Core Systems = 63.4% of the book | Write one category RFP, not five software buys |
| Vendor A = 63.4% of spend | Demand an all-in licence; do not rebuy unbundled Islamic / treasury modules |
| FY2025 maintenance = 22.3% of the core licence | Put a **ceiling rate** in the RFP (case target 17.5%) |
| Cloud / sandbox = USD 1.48m over three years | Require Dev/Test/DR in the price |
| Consulting = USD 12.70m as life-support for an ageing core | Cap post-award consulting to change-control, not standing patches |

## 2. Levers that move money

1. **Rate** — freeze maintenance for the full term; no silent 5% step-up.
2. **Inclusion** — sandbox, after-hours, and named modules inside TCO.
3. **Cash timing** — 10% advance against a guarantee; the rest on accepted milestones.
4. **Unit price** — man-day frozen for seven years, not five inside a seven-year term.
5. **Leakage** — any new SKU that duplicates awarded scope is a governance event, not a new PO.

## 3. What is not a lever

- Cutting national rails (SADAD / SARIE / SWIFT / IPS). Those are mandates.
- Cutting training below 500 staff plus 500 hours of knowledge transfer. That saving returns as a failed cutover.
- Taking Vendor C’s published price. Hidden-fee TCO reversed that bid by +91%.

## 4. Gate into negotiation

Do not open commercial talks until:

- Section B of the DDQ is a clean Yes on every environment.
- The five-year TCO (not the cover price) is on the scoring sheet.
- BATNA is a rewritten, on-kingdom Vendor A book — not the historic A contract.
